Eaglercraft activity

Connect this extension to your MINECORD account.

Pair extension

Generate a one-time code from MINECORD Settings → Eaglercraft browser integration. The code expires after five minutes and is validated by your MINECORD server.

What is shared

When paired, the extension reports only whether the supported Eaglercraft page is active. It does not read the game username, server address, browser history, cookies, passwords, or other websites.
